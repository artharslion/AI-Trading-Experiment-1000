# AI Trading Experiment 1000

用 **¥1,000 实盘资金**，检验 AI 在 **6 个月**里自主决策（不靠人类选股）是否盈利、是否跑赢被动指数投资。全部交易以**实际成交**为准，未成交不得记成收益。

> **当前状态：PRE_LAUNCH（待启动）。** 仓库已建立实验制度，不代表已入金、已下单或已产生收益。

## 实验概览

| 项目 | 预设 |
|---|---|
| 初始本金 | ¥1,000，仅一次性入金，不追加 |
| 市场 | 中国 A 股普通股票、符合条件的非杠杆场内 ETF、现金 |
| 计划期间 | 2026-11-10 至 2027-05-10（北京时间）；以首次可执行交易日记录实际起点 |
| AI 权限 | 自主研究、选股、择时、仓位、买卖或持币；**不直接操作证券账户** |
| 人类权限 | 开户、核验信息、按原样执行合法有效订单、反馈回报、风险/合规否决；不提供买卖建议 |
| 对照 | 510300 ETF 买入持有模拟组合（¥1,000，含适用费用）、100%现金 |
| 复盘 | 每周一收盘后决策；每周末记录资产；第 3、6 个月阶段性评价 |
| 状态 | **待启动，尚无任何实际交易或绩效** |

## 四个重要原则

1. **事前决策、事后成交**：AI 每次决策先提交带时间戳的 Markdown 文件和 Git commit，再由人类下单。未锁定的“建议”不能记作有效交易信号。
2. **亏损也保留**：既有决策与成交只追加更正条目，禁止直接改写旧记录。Git 提交历史是审计线索，不等同于不可篡改的外部审计。
3. **本金与真实费用**：账户总权益 = 现金 + 持仓市值 + 已确认未入账权益；成交价、佣金、税费取券商成交单，不用预测价代替。
4. **模型可升级，历史不重置**：每次决策写明模型与升级信息；升级不意味着之前的收益“归零”，不能用升级后的表现冒充固定模型验证结果。
